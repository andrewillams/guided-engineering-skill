# Sources and Evidence Template

Use this template for `docs/engineering/SOURCES.md`.

The purpose is not to collect links. The purpose is to preserve the evidence used to make important product, domain and technical decisions.

## Source hierarchy
Prefer, in this order when applicable:
1. Existing project behavior, code, configuration, logs and real sample data.
2. Official vendor/product documentation.
3. Applicable standards, regulations or authoritative domain references.
4. Primary technical material such as specifications, RFCs and official repositories.
5. Reputable secondary sources.
6. Community discussions for practical pitfalls, never as the sole authority for critical behavior.
